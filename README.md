# Milen Popat — Portfolio

A personal portfolio styled as a Minecraft menu: a title screen, an experience
timeline, a world-select list of projects, an enchanting table of skills, and a
player-profile About page. Next.js 14 (App Router) + TypeScript + Tailwind CSS,
shipped as a fully static export.

No game assets are used. The font is [Monocraft](https://github.com/IdreesInc/Monocraft)
(SIL OFL 1.1); the textures are generated by `scripts/gen-textures.mjs`; the item
icons are hand-authored pixel grids rendered to SVG; the button click is
synthesised with WebAudio. Not an official Minecraft product, and not approved by
or associated with Mojang or Microsoft.

## Commands

```bash
npm install       # once
npm run dev       # http://localhost:3000
npm run check     # typecheck
npm run build     # static export → out/
npm run textures  # regenerate the pixel textures
```

Deploy: serve the `out/` directory from any static host. Opening
`out/index.html` directly as a file works for a single page, but cross-page
navigation needs HTTP (`npx serve out`).

## Swapping in content

All copy lives in one file: **`data/content.ts`**. Nothing in the components
needs to change for content edits.

- **Projects** — each entry has `github` (and optional `demo`); an empty
  string renders no link. `data/projects-index.ts` folds featured projects,
  smaller projects and the research feature into the single list the projects
  screen shows.
- **Skills** — the four `toolGroups` map to the four tools on the enchanting
  table, in order.
- **Resume** — the live PDF is `public/resume.pdf` (currently the CS / 2029
  grad variant). It's a snapshot: re-copy after resume updates.
